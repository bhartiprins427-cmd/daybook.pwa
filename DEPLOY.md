# DayBook PWA deployment

This folder is a static, installable PWA. Serve it over HTTPS for service-worker installation (localhost is also allowed for development).

Recommended: GitHub Pages. Publish the contents of this folder as the repository root or `/docs`; Pages provides HTTPS automatically.

Data stays in the browser via localStorage. Use **Backup** to download `daybook-backup-v4.json` and **Restore** to validate and replace the local dataset.
